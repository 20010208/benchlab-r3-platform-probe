# benchlab-r3-platform-probe

Throwaway repository used only to test GitHub platform behaviour assumed by a shadow-operations design (branch/tag protection, token permissions, runners, schedule, concurrency).
All fixtures are synthetic. It contains no model, no candidate material, no data and no credentials. The workflow `shadow.yml` is a byte-exact copy of the design's (not enabled for production) workflow; the `probe-*.yml` workflows are test harnesses.
